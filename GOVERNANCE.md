# Governance

**AgentMemory for Codex on Windows** is currently an owner-maintained Technical
Preview.

- Repository owner: [M-T-D-N](https://github.com/M-T-D-N)
- Supported downstream profile: native Windows with OpenAI Codex
- Upstream project: [rohitg00/agentmemory](https://github.com/rohitg00/agentmemory)

The repository owner decides scope, reviews pull requests, and creates
releases. Public issues and pull requests provide input but do not imply a
support commitment or roadmap promise.

Upstream AgentMemory governance does not govern this independent downstream,
and this downstream does not speak for upstream. Contributions derived from
upstream remain subject to the Apache-2.0 license and preserved attribution.

Changes to licensing, supported data formats, project-scoping guarantees,
security reporting, or the relationship with upstream require an explicit
documented decision before release.
