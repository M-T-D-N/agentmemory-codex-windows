# Support

This is an experimental, source-built Technical Preview for experienced
Windows/Codex users.

Public issues are appropriate for reproducible downstream bugs and focused
feature requests. They are not a private support channel. Never attach
credentials, memory databases, private prompts, user workspaces, or unredacted
logs.

The project does not promise response times, compatibility outside the
documented Windows/Codex profile, npm support, or upstream support. For
unchanged upstream behavior, use the upstream AgentMemory project.

Security reports must follow [SECURITY.md](SECURITY.md).
