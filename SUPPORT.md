# Support

This is an experimental Technical Preview for experienced
Windows/Codex users.

Public issues are appropriate for reproducible downstream bugs and focused
feature requests. They are not a private support channel. Never attach
credentials, memory databases, private prompts, user workspaces, or unredacted
logs.

The project does not promise response times, compatibility outside the
documented Windows/Codex profile, upstream npm-package support, or upstream support. For
unchanged upstream behavior, use the upstream AgentMemory project.

Start with the [pinned installation guide](packaging/windows-codex/npm/README.md) for the prebuilt Windows release. Building from source is an alternative, not a requirement. For a setup failure, include the release version, Windows/Node/Codex versions, the failing phase (preparation, activation, or connection), the expected result and a short redacted error in a [downstream issue](https://github.com/M-T-D-N/agentmemory-codex-windows/issues/new).

Security reports must follow [SECURITY.md](SECURITY.md).
