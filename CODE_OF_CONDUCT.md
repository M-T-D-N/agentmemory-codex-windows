# Code of Conduct

This project follows the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
and the [GitHub Community Guidelines](https://docs.github.com/site-policy/github-terms/github-community-guidelines).

Be respectful, discuss ideas rather than people, and do not harass, threaten,
or disclose another person's private information.

For abusive content on GitHub, use GitHub's **Report content** flow. If a public
project issue is safe and does not reveal private information, it may also ask
the repository owner to moderate a thread. Do not use a security advisory for
a conduct dispute unless the report also describes a software vulnerability.

Enforcement may include a warning, removal of content, temporary interaction
limits, or a ban from project spaces.
